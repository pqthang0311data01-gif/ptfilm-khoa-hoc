# Trang giới thiệu Khóa học Dựng phim chuyên nghiệp

Dự án mẫu của **#PTFilmProduction** để làm quen với GitHub.

Đây là một trang web một trang (landing page) giới thiệu khóa học dựng phim của Mr.Thắng.
Khi bật **GitHub Pages**, trang này sẽ có đường link thật, miễn phí, dạng:

```
https://<ten-tai-khoan>.github.io/ptfilm-khoa-hoc/
```

## Trong thư mục có gì

| File | Dùng để làm gì |
|---|---|
| `index.html` | Nội dung trang web (chữ, bố cục) |
| `style.css` | Màu sắc, font chữ theo nhận diện PT |
| `README.md` | File giới thiệu này, GitHub tự hiện ở trang đầu repo |

## Muốn sửa nội dung

1. Mở `index.html` trên GitHub, bấm biểu tượng cây bút (Edit).
2. Sửa chữ, ví dụ đổi lịch học hoặc thêm một dòng nội dung.
3. Bấm **Commit changes**, ghi ngắn gọn đã sửa gì.
4. Đợi khoảng 1 phút, trang web tự cập nhật.

Mỗi lần sửa đều được GitHub lưu lại trong mục **History**, sửa sai thì quay lại bản cũ được.
